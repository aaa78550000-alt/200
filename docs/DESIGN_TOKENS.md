# Design Tokens 與 UI 元件契約

## 基礎色（初始色票，允許在符合品牌意圖與 WCAG AA 的條件下校正）
`--canvas: #F7F8F5`、`--surface: #FFFFFF`、`--primary: #267D76`、`--primary-hover: #206C65`、`--ink: #253239`、`--muted: #68757A`、`--border: #E6EAE5`、`--warning: #DCA85C`、`--danger: #B74848`、`--success: #318264`。

使用狀態色時加明確文字或 icon，不得單靠顏色辨識。小字／按鈕先檢查色彩對比，不合格就調深。

> 實作校正紀錄見本檔末「實作值」。

## 字體
台灣繁體優先 Noto Sans TC 或適當系統字體（PingFang TC 等），英數可用 Geist，但中英混排要一致。建議階梯：12（純註解）/14（輔助）/16（正文）/18（卡標題）/20（小節）/24（頁標題）/30（展示）。長姓名須有換行/截斷的可預期規則，不以極小字硬塞。

## 幾何
間距只從 4/8/12/16/24/32/48/64px 選用（偶有數值例外必須記理由）；一般卡 12px，彈層 16px，輸入框 8px，按鈕 8px；巢狀半徑依內距調整。避免密密麻麻套卡。

## 常用元件
- **PetAvatar** 40（搜尋）/52（預約列表）/96（檔案），object-fit cover、可存取 alt、灰階 fallback、可載入失敗。
- **AppointmentRow**：手機高度 88～104px；主要資訊時間、毛孩名字、服務、指派美容師與狀態；資料多時入詳情。
- **StatusLabel**：標籤文字 + 小點/圖示；服務中、待確認、待接回、已完成、取消用固定語意。
- **PetProfileHeader**：主頭像、名字、品種/性別/年齡、體重與日期、注意事項。
- **AttentionPanel**：重要照護資訊，需標示「飼主提供」或「美容師觀察」及最近更新時間；未知／未填請標示。
- **AppointmentDrawer**：桌面側欄（約 380～440px），手機底部面板或全螢幕詳情，關鍵提交按鈕可見。
- **BookingStepper**：四步線上預約，手機下一步固定底部安全區（避免鍵盤遮住）。
- Form、Dialog、Toast：loading/empty/error/success、鍵盤 focus、esc、說明文字清晰。

## Responsive
- 390px 手機主要目標（加測 375px），單欄、底部「今日／預約／毛孩／更多」四項。
- 768~1024px 平板需要檢查細密欄位與點擊區域。
- 1440px 桌面左側導覽（約 216～240px），主區域有適合長期工作的一覽排程。不要把手機小卡直接拉成巨大卡。
- 可互動目標建議至少 44×44px；表格在手機要改為操作列表而非橫向溢出。

## 攝影素材
能取得授權的清楚毛孩照片；統一裁切、比例、分類：頭像／美容前／美容後／照護／事件。不能使用生成示例聲稱是真實店家資料。

## 反模式
大面積漸層、模糊背景、三排 KPI 方塊、所有區塊同尺寸、重複文案、低對比 12px 小字、動畫占用工作時間、沒資料卻顯示假績效數字。
