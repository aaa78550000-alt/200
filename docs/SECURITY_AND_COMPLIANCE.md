# 資安、法規與營運風險清單

## 個資
飼主姓名電話、寵物與照護紀錄、照片及契約屬需保護的資料。需有蒐集目的告知、最少權限、依角色存取、下載授權、資安事件處理、資料匯出與刪除機制。跨店共享必須經過適當授權，不能因同一飼主在兩家店來過就自動合併資料。正式法規審查未完成前不可對店家宣稱全套合規。

## 電子契約
依台灣最新犬貓美容定型化契約與電子簽章相關規範檢查：審閱、契約版本、客戶確認、時間身分證據、內容不可竄改、文件取得與保存。簽名塗鴉不自動等於充分合法電子簽章。重大版本變更採新版本；預付／包套金額和履約保障需法律專業檢查。

## 金流與訂閱
P0 只記錄外部收款，不能假裝自己處理刷卡；日後接真金流需正式 provider 和 webhook 驗證、訂單對帳、退款、錯誤恢復。預付金不能直接修改餘額。

## LINE
各店 LINE OA 授權與密鑰安全保存、webhook 簽章、重複事件處理、訊息費／配額控管；顧客的交易通知與行銷通知有不同使用目的與同意管理。送出不代表顧客已閱讀。

## AI 與醫療
AI 只能整理已授權資料、提供店員確認的草稿或回訪建議，不得自己診斷疾病、要求停藥或在沒有確認下決定寵物安全。

## 測試與上線
使用虛構 seed、不用真實飼主資料測試。RLS、SQL injection、防越權、Storage signed URL、API rate limit、Session / OAuth、日誌個資遮蔽、備份/還原、依需求設置資料保留策略。正式上線前安排獨立安全與法律審查。
