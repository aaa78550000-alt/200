2. 待接回時，收款區（應收／已收／尚欠＋主要按鈕「記錄收款 NT$650」）移到主要動作區，交接緊接其下；「收款」與「接回」仍是兩個獨立動作。

## 七個評審問題（Round 2 後自答）
1. **第一眼最重要的操作**：今日＝「店內」區與每列唯一的快速動作（完成美容／收款・交接／報到）；詳情＝進度條下的單一主要按鈕。✔
2. **主從**：時間（等寬）→ 證件照 → 名字（17px bold）→ 服務/美容師 → 狀態。✔
3. **可刪**：已刪 KPI 卡（改成可篩選的三個計數）、深色側欄、卡片外框。「已結束」預設收合。
4. **390px**：主要按鈕 ≥ 44px；列高約 96–120px（含注意事項行，略高於 blueprint 104 上限，換來照護資訊在列表即可見）；**已知例外**：列內快速動作 36px 高（寬 ≥ 64px），刻意縮小避免搶走主要閱讀，記錄於此。
5. **失敗/空值**：無照片 → 灰階證件照 fallback；無體重/生日 → 「未提供」；空清單、搜尋無結果、離線、店休皆有文字（見 `state-*` 截圖）。
6. **1440 vs 390**：桌面是帳簿＋常駐詳情（master–detail）、行事曆是美容師欄×時間軸；手機是單欄帳簿與全螢幕詳情、行事曆是週列＋列表/單人時間軸。不是等比縮放。✔
7. **注意事項出現時機**：今日列（第一則重要事項）、預約詳情第一屏、毛孩檔案第一屏、新增預約選毛孩時。✔
